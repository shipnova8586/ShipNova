1. Introduction & Background

The contemporary freight and logistics industry forms the backbone of global commerce yet suffers from severe technological fragmentation. Mid-sized logistics enterprises traditionally manage fleets, shipments, and invoicing across disconnected spreadsheets and legacy on-premise software.

ShipNova is an enterprise-grade B2B Software-as-a-Service (SaaS) platform designed to consolidate fleet management, dispatch operations, carrier marketplace bidding, and tax invoicing into a unified cloud-native environment.

2. Problem Statement

  • High Hardware Barriers: Standalone GPS OBD-II trackers cost $200–$500 per truck, rendering real-time tracking unfeasible for small fleet operators.
  • Cross-Tenant Data Leakage: Traditional web applications fail to mathematically isolate database queries, risking confidential rate leaks between competing carriers.
  • Delayed Financials: Manual PDF invoice creation and payment reconciliation cause 10-15 minute administrative delays per shipment.
  • Unreliable Mobile Streams: Fleet tracking drops permanently during cellular tower handoffs (4G to Wi-Fi) on highways.

3. Project Objectives

  • Architect Strict Multi-Tenancy: Implement cryptographically enforced JWT tenant isolation ensuring 100% data privacy between enterprise companies.
  • Hardware-Free Live Telemetry: Stream real-time driver GPS telemetry via WebSockets (Socket.io) directly from standard driver smartphones.
  • Carrier Load Board Marketplace: Engineer an open load board enabling vetted independent carriers to place competitive bids on unassigned freight.
  • Automated B2B Financial Cycle: Integrate Razorpay SaaS subscriptions with instant PDFKit tax invoice generation and automated email delivery.

4. System Methodology

ShipNova followed the Agile Scrum Methodology spanning 4 months (June–Oct 2026) across six sprints. Development emphasized Component-Driven UI, strict middleware security, and continuous cloud integration.

Tenant Isolation Middleware:

Every incoming API request is cryptographically validated. The verified req.tenantId is automatically injected into all database operations, mathematically preventing data leakage across companies.

6. Core Implemented Modules

  • Live Telemetry Engine: Emits driver GPS coordinates via WebSockets with heartbeat ping/pong monitoring and 2-second auto-reconnection.
  • Public Load Board: Marketplace allowing external carriers to view unassigned freight and place competitive bids in real-time.
  • SaaS Subscription Gateway: Automated monthly checkout with HMAC SHA-256 webhook signature verification via Razorpay.
  • Automated PDF Invoicing: Server-side PDFKit engine computing dynamic CGST/SGST tax brackets and instant email dispatch.
  • Public Shipment Tracker: Token-free 12-character tracking portal accessible to end customers without account login.
